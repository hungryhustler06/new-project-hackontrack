🔒 How Record Integrity Verification Works
Each shipment is hashed with SHA-256 (Web Crypto API) on page load, creating a baseline fingerprint stored in localStorage. When you verify, the current hash is compared to the stored baseline.

VERIFIED = data matches baseline  |  TAMPER DETECTED = data changed since baseline was set.

⚠ Limitations: A mismatch proves data changed, not that it was fraudulent. The original data may not have been truthful. This is a client-side demo — not a blockchain, not a server, not a production integrity system.
